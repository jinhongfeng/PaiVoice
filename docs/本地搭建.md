# PaiVoice 电话项目 · 全本机搭建指南（Windows）

> 给"住在本地 Ollama 里的 AI 伙伴"打电话：浏览器拨号页 → 本服务（耳朵/嘴）→ Ollama 大脑。
> 耳朵 ASR = sherpa-onnx SenseVoiceSmall（本地 ONNX），大脑 = Ollama LLM，嘴 TTS = sherpa-onnx VITS 中文。
> 全程不依赖任何云端 API Key（模型已下载到 `models/`）。

## 一、架构

```
浏览器（拨号页 http://localhost:8780/）
   │ getUserMedia 麦克风 + WebSocket (PCM16 16k)
   ▼
server.py (:8780) ──ASR──► local_voice.py (:8792)  ──► SenseVoiceSmall (models/)
   │                      （本地语音边车）
   ├──大脑──► Ollama (:11434)  /v1/chat/completions（OpenAI 兼容 + SSE）
   │             模型: qwen2.5:7b-instruct（无思考模式，适合语音）
   ├──TTS──► local_voice.py (:8792) ──► VITS 中文 (models/)
   ▼
声音 + 双语字幕 回拨号页
```

## 二、启动 / 停止

```powershell
.\start.bat              # 双击启动（边车 + 通话服务）
.\scripts\stop.ps1       # 停止（按端口找进程）
# 或手动：pwsh -ExecutionPolicy Bypass -File scripts\run.ps1
```

Ollama 需先运行（Windows 托盘图标里打开；或 `ollama serve`）。
首次跑 `tools/models_download.py` 后模型已在 `models/`，无需再下。

## 三、拨号（无登录页，打开即接通）

1. 浏览器打开 http://localhost:8780/
2. 页面自动连接（ws 地址按当前页面自动推导，令牌由服务端注入，无需填写）
3. 说「你好」→ 她（它）会用本地 TTS 中文声回话，页面下方同步字幕

> 首次打开浏览器会询问麦克风权限，允许即可。若接通后听不到声音，**点一下页面任意位置**解锁音频（浏览器自动播放策略）。
> 手机同一局域网访问 `http://<电脑IP>:8780/` 同样自动接通。

拨号页还带一条打字条：不想说话可以打字对话（同样走大脑）。

## 四、换模型 / 调音

| 环节 | 变量（.env） | 说明 |
|---|---|---|
| 大脑 | `PAIVOICE_GATEWAY_URL` | 任何 OpenAI 兼容端点：本地 Ollama / DeepSeek / 硅基流动等 |
| 大脑人格 | `PAIVOICE_SYSTEM_PROMPT` | 口语化/润色要求，可改成你想要的任何人设 |
| **通话记忆** | `PAIVOICE_MYSQL_HOST` 等 | 直连 LLM 时的记忆：MySQL 存每轮对话并回放（见下节） |
| ASR | `PAIVOICE_ASR_PROVIDER` | `local`（本机）或 `siliconflow`/`groq`（云端） |
| TTS | `PAIVOICE_TTS_PROVIDER` | `local`（本机）或 `elevenlabs`（云端） |
| 换 Ollama 模型 | `ollama pull <模型>` | 建议非 thinking 模型（qwen2.5 系），语音延迟低 |

## 四·五、通话记忆（MySQL）

直连普通 OpenAI 兼容端点（本地 Ollama 等）时，**LLM 本身没有聊天记忆**——每一轮都是全新会话。
本服务支持把每轮对话落 MySQL（Navicat 里的 `hongfeng` 连接 = 本机 MySQL），请求时回放最近 30 条作上下文，
记忆**跨通话、跨重启**。

建库（一次性，或用 Navicat 手工执行）：

```sql
CREATE DATABASE IF NOT EXISTS paivoice DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE paivoice;
CREATE TABLE IF NOT EXISTS voice_call_turns (
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    call_session_id CHAR(32) NOT NULL,
    turn_seq INT NOT NULL,
    turn_id CHAR(32) NOT NULL,
    role ENUM('user','assistant') NOT NULL,
    content TEXT NOT NULL,
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    UNIQUE KEY uq_turn (call_session_id, turn_seq, role),
    INDEX idx_session_seq (call_session_id, id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

.env 配置（`PAIVOICE_MYSQL_HOST` 留空 = 关闭记忆，零依赖）：

```dotenv
PAIVOICE_MYSQL_HOST=127.0.0.1
PAIVOICE_MYSQL_PORT=3306
PAIVOICE_MYSQL_USER=root
PAIVOICE_MYSQL_PASSWORD=你的密码
PAIVOICE_MYSQL_DB=paivoice
PAIVOICE_MEMORY_TURNS=50
```

- 依赖：`.venv` 里 `pip install pymysql`（requirements.txt 已含）
- 每次拨号是新的 `call_session_id`，但历史回放**按同一个库**走——想让她彻底忘掉，删对应行即可
- 记忆故障绝不影响通话：MySQL 挂了只会看到 `[memory] save failed` 日志，通话照常（只是失忆）

## 五、文件清单

| 文件 | 作用 |
|---|---|
| `packages/local-voice/local_voice.py` | 本地语音边车：ASR + TTS（sherpa-onnx），端口 8792 |
| `tools/models_download_fast.py` | 下载语音模型（hf-mirror，大文件并行分块） |
| `packages/realtime-core/server.py` | 通话核心（加了 local ASR/TTS 分支、系统提示词、思考块剥离） |
| `tests/smoke_ws.py` | 文字链路冒烟（不需语音模型） |
| `tests/voice_ws.py` | 语音全链路冒烟（TTS 合成→当麦克风→走完 ASR/LLM/TTS） |
| `scripts/run.ps1` / `scripts/stop.ps1` / 根目录 `start.bat` | 启停脚本 |

## 六、常见问题

- **接通后没声音**：确认边车在跑（`curl http://127.0.0.1:8792/health`），
  且 `.env` 里 `PAIVOICE_TTS_PROVIDER=local`。
- **她说得慢**：qwen3 系默认带思考（先想十几秒才答），换成 qwen2.5 系（无思考）。
- **听不清 / 识别错**：SenseVoice 对中文效果好；保持环境安静，靠近麦克风。
- **换 VITS 音色**：`models/` 下换一个 sherpa-onnx VITS 中文模型目录，改 `packages/local-voice/local_voice.py` 里的 `VITS_DIR`。
- **模型目录误删**：重跑 `tools/models_download_fast.py`（支持断点续传）。
